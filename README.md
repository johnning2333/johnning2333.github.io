# Ning Zhang — Personal website

Academic homepage published at https://johnning2333.github.io/.

This is a static HTML and CSS site with no build step or external runtime dependencies.

- Edit `index.html` for biography, publications, and experience.
- Edit `style.css` for layout and appearance.
- GitHub Pages publishes the root of the `main` branch.

For a local preview, run `python3 -m http.server 8765` in this directory.
